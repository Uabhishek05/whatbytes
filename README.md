# Whatbytes Storefront Assignment

A polished ecommerce assignment built with Next.js, TypeScript, Tailwind CSS, and lucide-react.

## Features

- Responsive product listing page at `/`
- Header with logo, URL-connected search, cart badge, and profile avatar
- Sidebar filters for category, brand, and price
- URL-based filters such as `/?category=Electronics&price=29-500&q=phone`
- Product grid with responsive 3/2/1 column behavior
- Dynamic product detail route at `/product/[id]`
- Cart page at `/cart` with quantity updates, remove item, and price summary
- React Context cart state persisted in `localStorage`
- Conditional empty states for product search and cart

## Tech Stack

- Next.js App Router
- Tailwind CSS
- TypeScript
- lucide-react

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
